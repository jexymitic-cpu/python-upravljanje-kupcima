# Evidencija radnika i radnih sati – Python

## Opis projekta
Ovaj projekat je početnički Python program za evidenciju radnika, broja smena i ukupnih radnih sati u toku meseca.

Program koristi:
- Liste i rečnike (`list`, `dict`)
- `for` petlju
- `if/elif/else` uslove
- Funkciju `def` i `return`
- Izračunavanje radnih sati na osnovu smene od 8 sati

## Pokretanje programa
Program se pokreće u Python 3 okruženju. Korisnik unosi ime, prezime i broj smena, a program prikazuje rezultate i evidenciju radnika.

## Važna napomena
**Sva imena i prezimena radnika, broj smena i radni sati u ovom projektu su izmišljeni.**

Podaci služe isključivo za vežbanje Python programiranja i demonstraciju rada programa. Ne predstavljaju stvarne zaposlene niti stvarnu evidenciju radnog vremena.
